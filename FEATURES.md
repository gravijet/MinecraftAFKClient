# Client variants

| Cargo feature | Added functionality |
| --- | --- |
| default | Login, connection, chat and commands |
| `movement` | Movement commands |
| `items` | Inventory item data |
| `web-menu` | Browser inventory and menu viewer |
| `premium` | Movement, scoreboard, menu controls and anti-AFK |
| `pov-client` | First-person viewer |
| `ultra` | Combined optional features |

`build-all.sh` and `build-all.ps1` produce separate executables. Run a build with `--help` to see its supported options.
