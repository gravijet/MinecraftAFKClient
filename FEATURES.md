# Features

| Area | Standard (`afk`) | Live view (`pov-afk`) |
| --- | --- | --- |
| Login (Microsoft, offline, proxy, SRV, transfer, cookies) | yes | yes |
| Chat, `--cmd`, `--on` macros, reconnect with backoff | yes | yes |
| Physics: gravity, steps, jumping, sprinting, sneaking edges, water, lava, ladders, cobwebs | yes | yes |
| `:go`, `:jump`, `:look`, `:home`, `:route`, `:stop` | yes | yes |
| Scoreboard (`:board`), menus and items (`:menu`, `:click`, `:inv`) | yes | yes |
| Sneak, sprint, swing, use, hotbar, anti-AFK | yes | yes |
| Browser menu with original textures (`--pov-web`) | yes | yes |
| Camera image (terminal and browser) | – | yes |

Minecraft versions: 1.8.9, 1.21.1, 1.21.11, 26.1, 26.2, 26.3, 26.4 (pre-release 1 protocol).

Run a binary with `--help` to see its options; the panel reads its capabilities from there.
